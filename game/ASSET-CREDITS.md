# Rizo.game asset credits

## Wearable source silhouettes

The wearable artwork in `assets/wearables/` is original Rizo.game adaptation work built from selected source silhouettes in the **Game Icons** collection.

- Collection: Game Icons / game-icons.net
- Repository: https://github.com/game-icons/icons
- License: Creative Commons Attribution 3.0 (CC BY 3.0)
- License text: https://github.com/game-icons/icons/blob/master/license.txt
- Attribution: Game Icons contributors, including Lorc and Delapouite

Source icon slugs used or studied during the adaptation:

`bandana`, `headband-knot`, `winter-hat`, `sunglasses`, `vanilla-flower`, `eyepatch`, `headphones`, `gem-necklace`, `bull-horns`, `spiked-halo`, `bat-wing`, `crown`, `billed-cap`, `bow-tie-ribbon`, `steampunk-goggles`, `robot-antennas`, `solid-leaf`, `protection-glasses`, `cape`, `backpack`, `round-star`, `domino-mask`, and `outback-hat`.

The production files are not unmodified icon downloads. They were recolored, reshaped, combined, layered, outlined, cropped, and supplemented with custom Rizo-specific seams, straps, patches, knots, tails, lenses, pendants, medallions, and compact face marks to fit the canonical 520×670 Rizo canvas. Original source attribution and CC BY 3.0 terms remain applicable to adapted portions.

## Rizo artwork

The Rizo character, compact Rizo-face mark, branding, color direction, item concepts, and all custom adaptation work remain part of the Rizo project.

The V18 `shades-back.svg`, `shades-front.svg`, `headphones-body.svg`, `headphones-front.svg`, `bandana-back.svg`, `bandana-body.svg`, `bandana-front.svg`, `scarf-back.svg`, `scarf-body.svg`, and `scarf-front.svg` files are original Rizo.game redraws created locally for this project. ## Worker G Defense world plates

`assets/defense-ember-switchback.svg`, `assets/defense-moon-loop.svg`, `assets/defense-storm-circuit.svg`, `assets/defense-whiteout-pass.svg`, and `assets/defense-eclipse-ridge.svg` are original Rizo.game vector environment plates created locally for the Defense map/world pass.
